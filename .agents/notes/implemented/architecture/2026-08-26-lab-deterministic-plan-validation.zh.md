# Agent Note: 确定性计划校验保留来源与参数出处

Status: implemented

[English](2026-08-26-lab-deterministic-plan-validation.md) | 中文

## Problem

Agent 生成的计划可能结构完整，却丢失请求要求的来源，或使用引用 Skill 未声明的参数。计划状态本身也不能证明当前修订已经具备审查资格。

## Decision

领域校验器只接受 DRAFT 计划修订进入审批前校验。它检查计划引用是否来自当前检索集且没有重复，检查请求要求的引用是否被带入计划，并检查每个步骤引用是否同时列在计划级引用中。缺失或未知来源返回稳定的字段级问题。

每次计划校验上下文都为计划引用的 Skill 修订提供参数约束。校验器要求每个声明参数都出现，拒绝未声明参数，并确定性地判断单位和数值规则，例如正数、非负、非正、负数、上下界和显式单位。自由文本约束仍然是描述信息，只有包含这些受支持形式时才参与判断。

## Alternatives considered

**信任 Agent 的状态或说明。** 这会让过期或已改变的修订无需重复检查就进入审批，因此状态和字段分别校验。

**只把步骤引用当作充分来源。** 这会让请求级来源要求在计划中消失，因此分别检查必需引用和步骤到计划的引用归属。

**执行任意约束表达式。** 这会在规划路径引入无界解释器，因此首轮只支持有文档的小型确定性词汇，更丰富的结构化约束留给后续变更。

## Consequences

规划结果现在会在人工审查前区分检索缺口、来源丢失、计划状态错误和参数违规。校验器需要上下文提供 Skill 参数事实；需要更丰富约束的调用方应引入结构化约束类型，不应依赖未记录的文本语义。

## Testing

领域测试覆盖非 DRAFT 计划、必需来源与步骤引用一致性、正数/单位参数失败、未声明参数，以及已有的依赖、输入、操作、设备和 Skill 校验。本地规划和 Agent 工具组合测试在 CSV 表格片段标准化后通过。
