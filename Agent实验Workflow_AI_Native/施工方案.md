# AI Native 实验 Workflow 演示施工方案

## 目标

将原有以 W1–W7、数字员工和技术组件为中心的演示，改造为“用户给出实验目标后，产品能够完成什么”的 AI Native 应用演示。

统一案例为：12 份鼠脑新鲜冷冻样本的完整空间转录组实验。

## 页面结构

### 规划阶段

1. 用户描述实验目标。
2. Agent 理解完整实验目标。
3. Agent 根据 SOP 主动补齐关键信息。
4. 在对话中生成 8 个实验 Workflow 的确认卡片，详细信息从右侧侧栏展开。
5. 根据设备占用和其他正在进行的实验状态编排资源。
6. 生成可执行计划 v1.0。

规划页采用左侧对话、右侧当前计划的结构。当前计划可以收起，规划完善度和计划内容会随对话逐步更新。

其它项目复用原 HTML 中已录入的实验流程：EXP-2026-0415 为空间 ATAC 实验（52 步，发现 3 处缺口）；EXP-2026-0416 为客户自定义实验流程（28 步，发现 9 项隐性经验缺口）；EXP-2026-0418 为 SeekOne DD 单细胞文库构建（44 步，设备能力已绑定并正常执行）。

当前项目的资源编排引用 EXP-2026-0418 的 DD 液体工作站与 PCR 仪预约。用户可从设备占用信息跳转到该项目监控页确认状态；另外两个项目尚处于规划阶段，不申请执行设备。

### 执行阶段

1. 展示完整实验总体进度。
2. 展示当前 Workflow、具体步骤和 Executor。
3. 保留 Agent 对话与执行动态。
4. 模拟异常结果并触发 Agent 重规划。
5. 更新计划版本并继续执行。
6. 结果通过后完成实验归档。

执行阶段使用独立的流程监控布局，不复用规划页面结构。

### 独立步骤编排

步骤编排作为单独页面模块存在，支持：

- 拖拽调整尚未执行的步骤。
- 使用上移、下移按钮调整顺序。
- 在人工、机械臂、自动设备之间切换 Executor。
- 让 Agent 重新生成后续执行步骤。
- 返回执行监控或规划确认。

### 全局工作台与项目管理

每个实验作为独立项目管理。项目管理页展示 4 个实验项目及各自的阶段、流程状态、进度和资源状态。规划、确认、执行监控、步骤编排、归档属于当前单个实验项目。

知识库、Agent、Workflow、设备管理、人员与权限是跨项目通用能力，统一放在独立配置中心。工作台侧栏底部使用固定齿轮按钮进入配置中心，不设置工作空间下拉切换；各配置页不再嵌套另一套全局模块菜单：

- 知识库：先展示多个知识库项目及已录入内容，再进入具体知识库详情；详情页按知识域展示文档资料、SOP 步骤、参数规则、决策表、设备能力和历史经验。通过“录入知识”按钮进入原 HTML 的 F1–F5 资料提交、完整性检查、上传解析、冲突裁决、时间窗问答、F5 隐性经验缺口和发布流程。
- Agent：复刻原 HTML 的 9 个数字员工团队，展示 W1–W7 阶段、职责、能力、输入输出、协作移交和人工确认边界。
- Workflow：复刻原 HTML 的 SOP skill v2.2 编译摘要、决策表、设备绑定、版本锁定和三种 SOP 试编译；缺少流程时仍可预生成并编辑。
- 设备接入：复刻原 HTML 的 F3 设备台账、能力映射、通讯测试、DD/PCR/离心机绑定和 T7 手工回报兜底。
- 人员与权限：复刻 F4 人员与流程定义，管理人员、角色、资质、审批链、可用性和人工任务分配。

默认主项目 EXP-2026-0417 会发现“8 μm 鼠脑切片图像验收标准”和“切片图像质量检查 Workflow”两个缺口，并在对话中引导补齐。空间 ATAC 与客户自定义项目分别展示流程和知识缺口；SeekOne DD 单细胞文库构建展示信息完整、已有 Workflow 的正常执行路径。

### 三种页面上下文

1. 工作台只展示 AI 首页、项目管理和跨项目执行监控，配置中心作为侧栏底部独立入口。
2. 配置中心只展示配置总览、知识库、Agent、Workflow、设备管理和人员与权限，完成配置后返回进入前位置。
3. 进入项目后侧栏整体替换为项目总览、实验规划、计划确认、执行监控、步骤编排、结果与判断和实验归档，并提供返回项目管理与配置中心入口。

不同实验只复用项目生命周期与页面骨架，不复用具体 Workflow 和运行记录。项目定义保存实验步骤、依赖和执行示例；项目运行态按项目 ID 保存规划、执行、结果、异常、重规划版本和归档。空间 ATAC 使用染色成像、细胞核质控、转座与空间条形码、ATAC 文库流程；SeekOne DD 使用细胞悬液质控、芯片上样、液滴包裹、逆转录和文库构建流程；客户自定义项目保留隐性经验规则确认流程。

## 技术实现

- 单文件 `index.html`，包含 HTML、CSS 和 JavaScript。
- 无第三方依赖，无需构建，双击即可运行。
- 所有对话、规划、执行、异常、重规划和归档均为前端演示状态。
- 桌面端使用固定侧栏，窄屏使用抽屉式导航。
