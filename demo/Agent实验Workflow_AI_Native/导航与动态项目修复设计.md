# 导航与动态项目修复设计

## 修复目标

让工作台、单个项目和配置中心保持清晰的空间边界；任何项目都能稳定进入、退出和再次打开；首页发起规划后创建的项目立即可用。

## 信息架构

### 工作台空间

- AI 首页
- 项目管理
- 跨项目监控
- 底部公共入口：配置中心

### 项目空间

- 展示当前项目名称及项目内模块
- 明确提供“返回首页”和“项目管理”两个出口
- 底部公共入口：配置中心
- 不使用“返回进入前的位置”这类依赖历史状态的模糊入口

### 配置中心

- 只展示全局配置模块
- 仅提供一个上下文明确的返回入口：从工作台进入时返回工作台，从项目进入时返回对应项目

## 状态与交互边界

1. 侧栏只保留一个固定的底部工具区，各空间按需切换其中的按钮，隐藏状态不能被布局样式覆盖。
2. 首页“开始规划”先创建项目定义，再创建项目运行状态，最后进入该项目的规划页。
3. 新项目默认进入“目标理解与信息补齐”草稿状态，不复用其他实验的具体 Workflow；待信息补齐后再生成实验流程。
4. 返回首页、返回项目管理和进入配置中心均通过明确目标导航，不依赖浏览器历史记录。
5. 项目切换时保存当前项目状态，项目列表中的新项目可重复进入。

## 验收标准

- 任意时刻侧栏只出现一组有效的底部操作，不再堆叠多个返回或配置按钮。
- 从任意项目可以直接返回 AI 首页，也可以进入项目管理。
- 从首页创建项目后直接进入规划页，不再提示“项目不存在或已不可用”。
- 新建项目返回项目管理后仍可再次进入。
- 配置中心返回按钮的文案和目标与进入来源一致。
- 桌面端和窄屏状态下侧栏均能正常展开、收起和导航。

## 新建项目资料导入闭环

新项目的“实验信息缺口”状态必须提供下一步动作。规划对话底部保留输入框，同时提供“导入实验资料”入口。导入入口使用右侧抽屉完成资料类型选择、示例资料导入和解析预览；解析结果只回填已识别字段，并明确列出仍缺少的样本、产出和执行约束，不直接把 Workflow 标记为就绪。用户确认补充信息后，Agent 才进入 Workflow 选择或生成阶段。
