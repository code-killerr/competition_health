# 全局能力模块对齐原 HTML 设计

## 目标

将知识库、Agent、Workflow、设备接入和人员权限作为顶层侧栏中的独立全局模块。配置页内部不再重复展示全局模块菜单。知识库、Agent、Workflow 和设备接入的内容与交互参考原始 HTML 对应模块，同时保持当前 AI Native 实验工作台的视觉语言。

## 信息架构

- 顶层侧栏负责全局模块切换：项目管理、知识库、Agent、Workflow、设备接入、人员与权限。
- 单个配置页面采用单列主内容区，不再渲染 `module-menu` 二级导航。
- 项目内模块保持不变：规划、规划确认、执行监控、步骤编排、归档。
- 从项目缺口跳转到全局模块时，保留关联项目编号和缺口来源；处理完成后可以返回关联项目。

## 知识库

知识库模块采用“知识库项目列表 → 知识库详情 → 录入知识流程”三层渐进式入口。首页只展示不同知识域的知识库项目及其已录入内容摘要，不直接打开录入表单；详情页展示已结构化的知识条目，只有点击“录入知识”才进入原 HTML 对齐的 F1–F5 流程。

知识库列表包含空间转录组、空间 ATAC、SeekOne DD 单细胞文库和客户自定义流程四个知识域，卡片展示来源、知识条目数量、当前状态、缺口和更新时间。知识库详情按文档资料、SOP 步骤、参数规则、决策表、设备能力、历史经验分组展示已录入内容。主项目缺口入口直接打开空间转录组知识库详情并高亮待补齐条目。

录入流程参考原 HTML 的“资料提交与确认”阶段，包含：

1. F1–F5 资料提交模板及阻塞项/可降级标识。
2. 完整性检查；F1、F2 不完整时阻止进入解析。
3. 模拟上传 F1–F4 资料并展示文件列表。
4. 解析结果：13 项、156 页、107 步、621 字段、12 处冲突、23 处时间窗缺口。
5. F5 隐性经验缺口登记。
6. 冲突裁决和时间窗问答；完成后发布知识并回填关联项目。
7. 录入完成后返回知识库详情，更新知识条目和状态；返回列表不丢失当前录入进度。

## Agent 配置

参考原 HTML 的“数字员工团队（9）”，展示九个 Agent：知识库、确认问答、SOP 编译、实验管理、调度执行、设备接入、视觉判定、结果汇总、反馈优化。

每个 Agent 卡片展示职责、W1–W7 阶段、核心能力和输入输出。选择卡片后，在同页配置知识范围、Workflow 权限、可用工具、人工确认边界和启用状态。保留“职责单一、跨职责移交、人只在确认/裁决/署名/反馈节点介入”的协作边界。

## Workflow

参考原 HTML 的“SOP skill 编译结果”和“任意 SOP 试编译”，包含：

1. 当前空间转录组 SOP skill v2.2：39 步、7 个模板、5 张决策表、设备能力绑定、版本锁定。
2. 浓度、投入量、cycle 和边界归属决策表示例。
3. SOP 编译过程：步骤抽取、模板化、决策表、设备绑定、版本锁定。
4. 空间 ATAC、SeekOne DD 单细胞文库构建、客户自定义流程三种试编译结果。
5. 主项目缺少“切片图像质量检查”时，继续支持预生成、步骤编辑、Executor 绑定和发布回填。

## 设备接入

参考原 HTML 的 F3 设备台账、设备能力绑定和 T7 人工回报兜底，包含：

1. 设备台账、通讯状态、能力和当前项目占用。
2. 设备登记、能力映射、连接方式、连接测试和启用。
3. DD、PCR、离心机通讯能力及人工回报设备。
4. 通讯测试失败时切换人工回报，展示完成码与回报责任人。
5. 接入成功后可作为 Workflow Executor，并回到 Workflow 页面继续绑定。

## 人员与权限

移除内部重复菜单，保留人员、角色、资质、可用性、审批链、任务分配和权限边界。该页不额外扩展原需求之外的组织管理逻辑。

## 视觉与交互

- 延续深墨绿、暖白、薄荷绿和琥珀色状态体系。
- 使用阶段轨道、状态卡、数据摘要和明细表表达流程，不复制旧页面视觉样式。
- 所有交互仍为单文件 HTML 内的前端演示状态，不接入后端、真实设备或真实上传。
- 保持桌面与窄屏适配，长表格在窄屏允许横向滚动。

## 验证

- 配置页内部不存在重复的全局模块菜单。
- F1–F5、9 个 Agent、SOP v2.2 编译结果、三种试编译、设备通讯降级均可见且可操作。
- 主项目知识与 Workflow 缺口仍能完成跳转、发布和状态回填。
- JavaScript 可解析，静态 ID 无重复，OpenSpec 严格校验通过。
