# 需求文档

## 1. 应用概述

### 1.1 应用名称
SeekSpace · 空间ATAC转录组实验控制台

### 1.2 应用描述
这是一个湿实验自动化流程管理平台,用于空间芯片实验的全流程管理,包括实验管理、设备管理、样本建档、SOP执行、数据质控和审计追溯。系统采用前后端分离架构,前端使用React+Vite实现,后端接口使用mock数据模拟。

## 2. 用户与使用场景

### 2.1 目标用户
科研实验人员、实验室管理人员

### 2.2 核心使用场景
- 管理多个空间芯片实验的完整流程
- 管理实验设备(新增、编辑、删除、状态管理)
- 建档和质检实验样本
- 执行标准操作流程(SOP)
- 监控数据质量和实验结果
- 追溯实验过程和审计记录
- 查看系统仪表盘统计数据
- 对比多个实验的QC指标

## 4. 业务规则与逻辑

### 4.1 实验状态流转
实验状态按顺序流转:READY → RUNNING → COMPLETE → ARCHIVED

### 4.2 实验切换规则
- 切换当前实验后,工作区所有模块(实验总览、样本建档、SOP执行、数据质控、审计追溯)展示该实验的数据
- 侧边栏顶部显示当前选中实验信息

### 4.3 实验对比规则
- 必须选择2-4个实验才能进入对比页面
- 选中少于2个或多于4个时「对比实验」按钮禁用
- 对比表格中最优值高亮绿色,最差值高亮红色
- 最优值判断规则:
  - 有核率、总细胞核、单管投入、证据链数、追溯评分、实验进度、文库浓度:数值越大越优
  - 结团率:数值越小越优
- 雷达图中结团率需反向处理(100%-结团率)
- 总细胞核、单管投入、证据链数需归一化处理后展示在雷达图中

### 4.4 SOP执行顺序
7个步骤必须按顺序执行,前一步完成后才能执行下一步

### 4.5 设备管理规则
- 新增设备后加入设备列表,默认状态为在线
- 编辑设备时回填原有信息
- 删除设备需二次确认
- 设备状态可为:在线/离线/维护中

### 4.6 样本质检规则
- 有核率:显示百分比值
- 总细胞核:不超过200,000
- 单管投入:不超过25,000
- 结团率:需<30%
- 调整QC参数后可重新评估

### 4.7 放行条件判断
四项放行条件必须全部PASS才能继续:
- 设备注册
- 样本入场
- 核悬液QC
- 数据契约

### 4.8 数据加载流程
数据加载前后状态横幅切换显示

### 4.9 视觉检查规则
视觉检查条目需显示置信度和PASS状态

### 4.10 追溯评分计算
追溯度评分由三项子评分组成:设备绑定、样本门槛、数据来源

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 新建实验信息不完整 | 提示必填字段,禁止提交 |
| 删除实验 | 二次确认弹窗 |
| 归档实验 | 二次确认弹窗 |
| 选中实验数量不在2-4范围内 | 禁用「对比实验」按钮 |
| 对比实验中某实验缺少部分QC数据 | 对应单元格显示「暂无数据」 |
| 设备信息不完整 | 提示必填字段,禁止提交 |
| 删除设备 | 二次确认弹窗 |
| SOP步骤未按顺序执行 | 禁止跳步执行 |
| 核悬液质检参数超出阈值 | 显示警告状态 |
| 放行条件未全部PASS | 禁止进入下一阶段 |
| 数据文件缺失 | 显示缺失状态 |
| 视觉检查置信度过低 | 显示警告或FAIL状态 |
| 产物链接状态为PENDING | 显示待处理状态 |
| 切换实验时当前实验有未保存数据 | 提示保存或放弃 |

## 6. 验收标准

1. 用户打开应用,看到仪表盘首页,显示关键统计指标和最近实验列表
2. 点击「新建实验」按钮,填写实验信息并提交,新实验加入实验管理列表
3. 点击侧边栏「01 实验管理」,查看实验列表表格,勾选3个实验,点击「对比实验」按钮,进入实验对比页面
4. 在实验对比页面查看对比表格,最优值和最差值分别高亮显示,查看雷达图和分组柱状图
5. 点击对比表格中某实验列标题,跳转至该实验的实验总览页面
6. 返回实验管理页面,点击「切换为当前实验」按钮,侧边栏顶部显示该实验信息
7. 点击「04 设备管理」,查看设备列表表格,点击「新增设备」按钮,填写设备信息并提交,新设备加入列表
8. 点击设备操作列的「编辑」按钮,修改设备信息并提交,设备信息更新
9. 点击「05 样本建档」,查看当前实验的样本信息和核悬液质检面板,调整QC参数滑块,点击「重新评估」按钮
10. 点击「06 SOP执行」,查看9步实验时间线,点击「运行SOP」按钮,步骤状态从pending变为active再变为done
11. 点击「07 数据与质控」,查看分析输入清单、文库质量卡、空间定位预览和基因表达信号
12. 点击「08 审计追溯」,查看追溯度评分96分、事件日志表格,点击「导出实验报告」按钮,下载JSON格式报告
