## Context

原页面是一个 793 行的单文件 HTML 演示，交互完整，但主叙事聚焦 W1–W7、9 个数字员工、模板编号和内部技术能力。新版仍需保持单文件、无构建依赖和双击可运行，同时把用户体验改为 AI Native 的完整空间转录组实验工作台。

页面面向演示而非真实实验控制。所有对话、规划完善度、运行进度、异常、重规划、拖拽编排和归档均为浏览器内预设状态。

## Goals / Non-Goals

**Goals:**

- 用完整空间转录组实验说明产品从目标到归档能完成什么。
- 形成规划与执行两个清晰的一级阶段。
- 让对话持续推动计划完善，而不是作为附属聊天窗口。
- 让当前计划可见、可收起，并在执行阶段转换为流程监控界面。
- 通过三个优化案例和一个异常重规划案例证明 Agent 的规划价值。
- 将手动步骤编排放在独立页面模块中。
- 将跨项目通用能力放入全局工作台，并与单个实验项目的规划和执行模块分离。
- 支持主实验发现能力缺口后跳转补齐并返回规划。

**Non-Goals:**

- 不调用真实模型、设备、数据库或后端接口。
- 不实现真实实验控制、权限、安全审批或数据持久化。
- 不覆盖或重构原始 HTML。
- 不承诺真实效率、成功率或实验结果。

## Decisions

### 1. 保持单文件交付

新版以一个 `index.html` 承载结构、样式与脚本，确保演示环境无需安装依赖。相比拆分组件或引入框架，单文件更适合当前交付方式；内部仍按数据、渲染和事件函数划分代码区域。

### 2. 两个一级阶段，多个独立页面模块

侧栏主导航包含规划实验、规划确认、执行监控、步骤编排和实验归档。规划模块围绕目标理解、信息补齐、流程选择与优化；执行模块围绕进度、当前 Workflow、Executor、结果、异常和重规划。相比一条十步长页面，这种结构更符合规划完成后进入执行的产品状态变化。

### 3. 对话驱动加生成式任务空间

规划页左侧为对话，右侧为可收起的当前计划。预设回答按顺序推动规划完善度并更新计划内容。任务空间收起后，对话区扩展，侧边窄条保留完善度摘要。相比全屏对话或纯流程图，该组合兼顾 AI Native 感和计划可解释性。

### 4. 执行监控采用流程优先布局

执行页顶部展示总体进度和状态，中部展示 Workflow 时间线、当前 Workflow 步骤与 Executor，侧区展示 Agent 对话、异常与待办。规划阶段的完整计划可从侧栏返回查看，不重复占用执行主区。

### 5. 手动编排为独立模拟页面

步骤编排页展示未完成步骤列表、依赖关系和 Executor 选择。拖拽采用原生 HTML Drag and Drop，调整只影响页面演示状态。Agent 重规划使用预设方案切换，显示调整前后差异。

### 6. 优化能力基于项目与设备状态表达

资源编排直接使用当前完整空间转录组实验的 Workflow 依赖、5 台调度设备状态，以及其它独立实验项目的占用时间。其它项目复用原 HTML 中的空间 ATAC、SeekOne DD 单细胞文库构建和客户自定义实验流程；其中只有进入执行阶段的项目申请设备。用户可从占用信息进入对应项目监控核对状态。

### 7. 全局能力与项目内容分层

项目管理、知识库、Agent、Workflow、设备接入和人员权限属于全局工作台。单个实验项目内部只展示规划、规划确认、执行监控、步骤编排和归档。默认主项目可发现知识与 Workflow 缺口并跳转处理；空间 ATAC 与客户自定义流程展示规划缺口，SeekOne DD 单细胞文库构建展示已有 Workflow 的正常执行路径。

知识库采用“项目列表 → 详情 → 录入知识流程”的入口层级：列表展示多个知识域与已录入状态，详情展示已结构化知识条目，点击“录入知识”后才进入资料录入、解析结构化、缺口检查、人工确认和发布流程。Workflow 支持预生成、步骤与 Executor 编辑和发布；设备支持登记、能力映射、连接与测试；Agent 和人员权限提供配置入口。

### 8. 视觉方向

采用深墨绿实验工作台侧栏、暖白内容面板和少量琥珀色异常强调。避免紫色渐变、通用数据大屏和过量卡片。字体使用本地中文字体栈，不依赖网络字体。

## Risks / Trade-offs

- [单文件代码体积较大] → 使用明确注释分区、集中状态对象和复用渲染函数控制复杂度。
- [模拟对话可能被误解为真实 AI] → 页面显著标注“交互演示”，不展示真实连接状态或虚构模型指标。
- [窄屏信息密度高] → 在 1100px 以下改为单列，并让侧栏变为顶部抽屉式导航。
- [拖拽在触屏设备上体验有限] → 同时提供上移、下移和 Executor 下拉选项。
- [完整实验步骤过多] → 执行页先展示 Workflow 层级，当前 Workflow 再展开具体步骤。
