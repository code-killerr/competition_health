# lab-automation-mvp-foundation

实验自动化平台第一阶段最小原型：知识库录入与召回、Agent 规划、可插拔 Lab Skill、人工确认、设备接入、受控执行、结果验证与反馈；Space ATAC CSV、流程确认表、PDF 与鼠脑空间转录组仅作为测试数据。

本变更是 `/openspec explore` 的落地规格，来源于[第一轮敏捷开发规划](../../../docs/change_plan/第一轮敏捷开发规划.md)。它定义第一阶段要实现的系统能力与开发顺序，不修改现有 HTML demo，也不把示例资料固化为运行时流程。

## 文档

- [proposal.md](proposal.md)：变更动机、范围与能力清单。
- [design.md](design.md)：分层、包划分、服务接口、数据和安全决策。
- [specs](specs/)：可验收的能力需求与场景。
- [tasks.md](tasks.md)：按 I0–I4 增量拆分的开发任务。
